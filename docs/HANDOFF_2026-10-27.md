## 2. v1.77.0 改了什么（按文件）

### 注入与 embedding 桥接（2026-10-28 线上收尾）
- 线上证据（`backend.log` 48k 行）：49 次 `emb bridge ... timed out after 5.0s`、
  1 次 `auto inject timed out after 10.0s`；同一时刻实测 siliconflow 端点 8 次 0.29–0.52s（4096 维），
  说明不是「API 慢」，而是超时结构把预算重复花在同一个卡住的 provider 上。

  每个 await 只拿剩余时间，provider 按 `id()` 去重，预算耗尽即中止后续解析。

  加载 banner 去掉硬编码版本与手转义标签（改为 `_DIARY_BLOCK_LABEL`）。
- 测试：`_smoke_v84` 增加「同一 provider 走两条路径只花一份预算」（0.4s < 0.75s）；
  `_smoke_v70` 增加「stop 置位后不改 req、未置位仍注入」。全量 85/85 绿。

## 4. 已知的坑（踩过）

- smoke 全量跑要设 `TEMP` 到工作区外，否则 `TemporaryDirectory` 清理报 PermissionError
- `run_code` 的 TS 模板字符串不能出现反引号；Python 补丁脚本里的 `\n` 要用 raw 字符串
- `edit` 前必须 `read`（文件被脚本改动后会提示 stale）
- 大文件批量替换建议用 AST 脚本（本仓 `tests/_smoke_v*.py` 里没有 `__init__.py`，直接 `python 文件` 运行）
- 写补丁脚本时，若原始代码是单行 `except X: pass`，按「替换 pass 所在行」会把 except 头一起删掉；
  批量改写前先扫 handler.lineno == body[0].lineno 的单行块，或整块 AST 重写。
- run_code 的 TS 模板字符串（String.raw）里不能出现反引号；输出 markdown 反引号时，
  在 Python 脚本里写 \x60（Python 解析成反引号），不要写转义反引号。
